# 編輯審查清單

發布前依文章內容選擇適用項目，不把不相關的檢查硬套進文章。

## 事實查核

- 找出可客觀驗證、可能過時或容易誤解的敘述。
- 優先使用官方文件、原始專案、研究、公告或其他第一手來源。
- 開啟並閱讀來源本身，核對版本與日期，不只依賴搜尋摘要。
- 確認每個來源直接支持對應敘述；時效性資料註明適用時間。
- 將個人實測與外部事實分開，個人經驗交由作者確認。

## 校稿與結構

- 修正錯字、標點、重複句、指代不清與不自然的中英文空格。
- 檢查標題層級、段落順序、術語與專有名詞是否一致。
- 確認 title、description、category 與 tags 能準確描述內容。
- 保留作者語氣；較大幅度的重寫或觀點調整列為建議。

## 來源與內容補強

- 為需要佐證的敘述補充可直接支持它的來源。
- 依 `drafts/_template.md` 的格式，保留正文中的就近連結，並在文末「參考資料」彙整實際引用的來源；不要因建立文末清單而移除正文連結。
- 檢查外部連結可用性，避免連到搜尋結果或無關首頁。
- 指出缺少的背景、限制、反例、安全提醒或版本差異。
- 技術文章核對指令、程式碼、版本與操作步驟；能在本地安全驗證時執行驗證，不能驗證時註明限制。
- 檢查內文圖片路徑、替代文字及圖片與段落的對應關係。

## 定稿門檻

- 事實錯誤與發布阻擋已解決。
- 待作者確認的個人經驗、測試結果和結論已取得回覆。
- 文章主旨與主要段落不再有方向性變更。
- title、description、category、tags、來源和連結已確認。
