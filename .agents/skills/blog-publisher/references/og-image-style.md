# OG image 視覺規範

這是全站文章封面的共同風格來源。只有作者確認過、可跨文章重用的視覺決策才能加入正式規則；單篇文章特有的元素不提升為全站規則

## 固定規格

- 用途：文章列表封面、Open Graph 與 Twitter Card
- 原始輸出目標：`1200 × 630`，橫式構圖
- 正式來源檔：`posts/<YYYY-MM-DD-slug>/cover.jpg`
- 畫面需在中央裁切與縮小成卡片時仍保有清楚焦點
- 不生成文章標題、段落、標語等敘述性文字，也避免細小或無法辨識的假文字
- 與文章主題直接相關的 Logo、品牌名稱與指令名稱可以出現，但不得只是無關裝飾；水印仍不使用
- 不直接輸出至 `public/generated/posts/`；WebP 和多尺寸版本交由既有 build 流程產生

## 全站視覺語言

### 插畫風格

- 使用精緻的 soft-3D 編輯插畫，以黏土感的數位造型、簡化且圓潤的幾何
  形式呈現
- 材質以平滑霧面塑料為主，搭配細膩的立體明暗；避免過度光亮
- 採略帶等角透視感的 2.5D 視角，整體現代、專業且成熟，不走幼稚可愛
  路線
- 風格化而非寫實，維持 SaaS、開發者工具與科技媒體常見的乾淨質感

### 色彩與光線

- 背景配色依當篇文章主題決定；同一張圖的背景、主體與點綴色需形成一致且能呼應主題的色彩系統
- 使用柔和環境光、陰影與輕微 bloom，重要物件可加入明亮輪廓光
- 可用少量高對比色作為視覺重點，但避免每個物件都使用過多漸層
- 保留柔和的體積光與適度景深，主體必須清晰

### 構圖與內容

- 以一個清楚的核心物件或概念作為視覺主角，周圍配置與主題相關的輔助物件
- 構圖平衡並保留充足負空間，以前景和背景元素建立細微景深，確保縮圖與中央裁切時仍有明確層級
- 背景可加入少量抽象科技 UI 元素、粒子、連接線或幾何形狀，但不可造成視覺雜亂
- 技術主題可依內容選用程式碼視窗、終端機符號、資料庫、雲端服務、伺服器、API 連線、開發工具、瀏覽器視窗、齒輪、節點、游標或抽象軟體圖示
- Logo、品牌名稱與指令名稱可在符合文章內容時出現，且應作為主題資訊的一部分；不加入文章標題、段落、標語或其他敘述性文字

### 品質與避免事項

- 畫面需細緻到具有高品質、成熟的 3D 編輯插畫質感，但不堆疊無關細節
- 避免照片寫實、平面向量、動漫、手繪、幼稚卡通、過度光亮材質，以及與主題無關的隨機裝飾物
