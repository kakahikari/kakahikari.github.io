# OG image 視覺規範

封面與內文生成圖的共同風格以 [文章圖片共同視覺規範](../../references/article-image-style.md) 為準；本文件只補充封面規格，製作 OG image 時兩者都需讀取

## 固定規格

- 用途：文章列表封面、Open Graph 與 Twitter Card
- 原始輸出目標：`1200 × 630`，橫式構圖
- 正式來源檔：`posts/<YYYY-MM-DD-slug>/cover.jpg`
- 畫面需在中央裁切與縮小成卡片時仍保有清楚焦點
- 不生成文章標題、段落、標語等敘述性文字，也避免細小或無法辨識的假文字
- 與文章主題直接相關的 Logo、品牌名稱與指令名稱可以出現，但不得只是無關裝飾；水印仍不使用
- 文章以可明確識別的產品、專案或品牌為核心時，先從官方來源核對其識別，並將必要識別作為主題資訊的一部分；沒有適合識別或作者要求不採用時才省略
- prompt 不使用 `no logos`、`no company logos` 等一律排除品牌的限制；明確列出必要識別，並只禁止未列出的無關 Logo 與品牌
- 不直接輸出至 `public/generated/posts/`；WebP 和多尺寸版本交由既有 build 流程產生

## Prompt 骨架

依文章內容填入，不要把本段直接當成成品 prompt：

```text
為「光Lab.」部落格文章製作 1200×630 的橫式 OG image。

文章核心：<一句話摘要>
主要視覺：<一至三個具體物件或場景>
氛圍：<文章希望傳達的情緒>
主題配色：<依文章主題選擇背景、環境光與少量點綴色>
構圖：主體在縮圖尺寸仍清楚，保留適當留白，避免邊緣重要細節
風格：精緻的 soft-3D 科技編輯插畫；圓潤幾何造型、霧面材質、2.5D 視角、柔和光影與清晰主體，遵守文章圖片共同視覺規範，並與同篇內文生成圖保持一致
必要識別：<與主題直接相關且需要出現的官方 Logo、品牌名稱或指令名稱；沒有則填無並說明原因>
禁止識別：<未列入必要識別的 Logo、品牌與容易混淆的標誌>
限制：不放文章標題、段落、標語等敘述性文字，不放水印、難以辨認的假文字、未指定品牌或與主題無關的裝飾
```

## 更新方式

只有作者確認可跨文章重用的視覺決策才更新共同規範；單篇文章的配色、物件與品牌需求不提升為全站規則
